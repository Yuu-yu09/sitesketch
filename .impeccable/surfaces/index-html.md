# Surface brief — SiteSketch

## Scope and visitor mode

Primary target: `index.html` (landing, Persuade). Related: `login.html`, `register.html`, `dashboard.html`, `plan.html`, `builder.html`, `publish.html` (all Operate).

Audience: students, beginners, small-business owners who cannot code. Job: turn a fuzzy idea into an organized website plan, then a published site. Action: "Start your plan." Proof: the builder visibly assembling a plan from a description. Constraint: plain beginner-friendly language; film/sketch jargon never enters UI labels; solid-defaults accessibility (keyboard, focus, contrast, labeled inputs).

Memorable moment: a blank quadrille page that visibly draws itself into a website structure — ink arrows snapping sections into place.

Unresolved: whether the graph-paper substrate carries the builder canvas at full density (roll with light density if it fights the task).

## Direction contract

THESIS: The page owns one idea — a website plan is a sketch before it is a site, drawn on the page the audience already plans on. It refuses the category default: purple/blue gradient hero over a 3-up feature-card grid, replaced by a working quadrille page where the plan visibly draws itself.

OWN-WORLD: Quadrille notebook ground — warm paper #FAF8F3 with pale blue-green grid rules (24px), blue-black ink #16283C for text and outlines, white index-card surfaces #FFFFFF with soft pencil-shade shadows, single accent pencil-red #D6452F (one supporting highlighter yellow #FFE95C used only for "selected/needs content"). Type: Bricolage Grotesque for display (700, tight), Figtree for UI/body (400/500/600), Spline Sans Mono for labels/tokens (uppercase, tracked), Caveat for marginalia annotations only. Buttons: 2px ink-outlined rectangles, 6px radius, filled ink for primary; hover = hand-drawn SVG underline stroke. No gradients, no glass, no glow.

STORY: The visitor arrives uncertain ("I don't know what a website needs"), sees the flow drawn as sketched frames — describe → plan → build → publish — understands SiteSketch recommends the pages and sections for them, and acts: Start your plan (register) or Open the builder demo.

FIRST VIEWPORT: full-bleed quadrille canvas; top-left a mono token bar (SiteSketch · v1 · IPT2) as a taped page header; left column headline "Sketch your website before you build it" with a hand-drawn ink circle around "Sketch", subcopy naming type → sections → published site, primary CTA "Start your plan" (ink-filled) + secondary "See the builder" (outline); right column a live index-card demo: a real builder card where recommended sections snap in under a hand-drawn arrow, with a Caveat annotation "drag me". Below the fold line the top edge of the next section (a taped strip of four flow cards) must be visible.
